Exam · 正式试卷

A4 / A3 / mixed

Exam 可以输出普通 A4、A3 双栏，以及 mixed 模式。mixed 允许在 A3 正文中插入独立 A4 页面，再恢复 A3。

页眉页脚

  • A4 / A3 可使用独立 Y 偏移。
  • A3 支持左右逻辑页页眉页脚。
  • 页脚支持 fixed / flexible / fill 三种距离策略。
  • 总逻辑页数不计封面、pre、print 和目录。

标题保护

questiongroup / part / chapter / section / subsection / subsubsection / examsectionnote 均进入统一标题防孤立策略；A3 左栏不足时自动进入右栏，右栏不足时进入下一张 A3。
