# FocusPomo 5.2.2 original asset roles

The binary assets in this directory are extracted from the user's decrypted FocusPomo 5.2.2 IPA and are used only by the user's private `/me/focus` reconstruction.

- `tomato.png`: `ic_tomato/tomato_default@3x.png` — home/physics normal tomato.
- `tomato-small.png`: `tomato_for_data_center_details/tomato_default@3x 1.png` — detail thumbnail.
- `tomato-interval.png`: `tomato_for_select_interval/tomato_default.png` — duration picker.
- `tomato-data.png`: `tomato_for_data_center/tomato_for_data_center@3x.png` — data center count/header.
- `tomato-config.png`: `tomatoForConfig/stiker_default 1.png` — settings/configuration picker.
- `fail_tomato1/2/3.png`: dedicated abandoned tomato variants.
- `fail-tomato-data.png`: `failed_tomato_for_data_center@3x.png` — data center abandoned item.
- `pause.png`, `continue.png`, `stop.png`: original count-up controls.
- `sound.png`, `sound-off.png`: focus sound controls.
- `back-data.png`, `prev-data.png`, `next-data.png`, `next-data-disabled.png`: original data-center navigation.
- `tag-arrow.png`: selected-tag disclosure arrow.
- `more.png`: settings/more icon.
- `picker-select.png`: duration picker selection marker.
- `app-icon.png`: rounded original app icon for private web favicon/surface.

Widget/Watch-only resources and 1024px App Icon dark/tintable renditions remain preserved in the full extraction archive. They are not inserted into browser surfaces that do not have corresponding native semantics.
