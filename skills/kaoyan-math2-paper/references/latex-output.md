# LaTeX 成卷输出规则

## 编译器

优先使用 XeLaTeX；如模板明确要求 LuaLaTeX，则按模板执行。

## 公式

- 题库正文只保存语义正确的 LaTeX，不把字体写死在每道题里。
- 数学字体、中文字体、页眉页脚等由统一模板控制。
- 复杂图形优先 TikZ/PGFPlots；若为题源原图且无需重绘，可使用外部图片。

## 题目结构

建议为每题保留：

```latex
\begin{question}
  % 题干
\end{question}
```

若接入现有 Everflow/ExBook 风格模板，可在渲染层映射到对应 `bbox`、题号、答案环境；题库数据层不要绑定某一版式。

## 图形

- 函数图像、坐标系：PGFPlots 优先；
- 几何、流程、结构示意：TikZ 优先；
- 图中文字和公式必须与正文数学字体协调；
- 编译后必须检查裁切、标签碰撞、线宽和灰度打印效果。

## 正式输出

至少生成：

1. `paper.tex`：试题卷；
2. `solutions.tex`：答案解析；
3. `paper.jsonl`：本次选题快照；
4. `blueprint.md`：双向细目表与组卷说明。

## 字体注意

不要为了模仿 MathType，在题目数据中手工替换每一个 `\int`。如需经典 MathType/Times 观感，应在统一数学字体层或自定义算子宏中处理，确保所有公式一致。
