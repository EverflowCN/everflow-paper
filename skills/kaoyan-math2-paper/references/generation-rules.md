# 真题风格与自编题规则

## 一、真题风格校准

生成 `real-exam` 难度题或 `mock` 仿真卷时，至少检查以下六项：

1. **题眼密度**：关键方法不能直接写在题干里提示。
2. **计算量**：避免大量无意义展开；难度应来自识别与组合，而不是纯手算长度。
3. **综合度**：允许 2–3 个大纲内知识点自然耦合，禁止为综合而硬拼。
4. **陷阱合理性**：易错点来自定理条件、符号、区间、秩/维数关系等真实考点。
5. **可解性**：在标准考试时间内存在清晰主路径。
6. **超纲检查**：不得依赖竞赛技巧、冷门结论或大纲外定理才能完成。

## 二、变式题生成

围绕母题生成变式时，至少改变一个“结构变量”，而不仅是数值替换。

可用方向：

- 改条件：充分条件/必要条件、参数范围、连续/可导条件；
- 改区间：对称区间、平移区间、分段区间；
- 改结论：求值 → 证明，存在性 → 唯一性；
- 改表示：显函数 → 隐函数，矩阵 → 线性方程组；
- 改耦合：与另一个大纲内知识点组合；
- 改题型：选择/填空 ↔ 解答，但必须重新设计信息量。

## 三、错误变式

针对错题生成补练时，优先保留导致错误的“认知冲突”，例如：

- 极限中局部等价替换的合法位置；
- 定积分换元后上下限变化；
- 中值定理使用前的条件核验；
- 线性相关/无关与秩之间的方向关系；
- 特征值、相似、合同概念混淆。

不要简单把原题数字改一下。

## 四、答案验证

### 客观题

- 重新独立求解一次；
- 检查干扰项是否唯一排除；
- 参数题检查边界值。

### 计算题

- 检查定义域、积分区间、常数项、绝对值；
- 允许时用另一种方法做交叉验证。

### 证明题

必须明确：

1. 使用哪个定理；
2. 定理条件为何满足；
3. 如何构造辅助函数/对象；
4. 如何推出目标结论。

## 五、整卷节奏

- 前部题目不应连续出现多个高计算量题；
- 综合题应逐渐增加知识点耦合；
- 同一核心技巧不要在相邻题中重复；
- 最难题应难在结构识别或综合，而不是人为设置超长运算。

## 六、来源标注

- `real_exam`：必须能核验年份与题号；
- `adapted`：说明“依据何种结构改编”，不要冒充原题；
- `generated`：明确为自编；
- 商业教材/题库内容若无授权，不批量复制原文。
