v24 审查与稳定性

官网集成版建立在 v24 全功能审查修复版之上。审查并不以“能生成 PDF”为唯一标准，而是检查配置优先级、死参数、极端值、关闭状态、非法值回退、连续编译、日志和像素回归。

当前已知边界

  • Public 从完全干净的辅助文件开始需要多遍收敛，构建脚本使用 latexmk 自动处理。
  • Windows 批处理已做静态修复，但 Linux 环境无法替代真实 Windows 运行态验证。
  • 内部宏名继续保留 ZeroOne...，这是兼容层，不代表用户可见品牌仍是旧品牌。
