## 使用位置

- 正封右上：横版 Everflow 标志
- 书脊顶部：品牌图标
- 分部页：独立红色图标
- Public 扉页：横版标志
- 网站导航与 favicon：SVG 图标

## 独立封面输出

Book / Exam / Public 均支持 `front / back / spine / front-back / panels / spread` 输出，并可控制出血、裁切线和参考线。
